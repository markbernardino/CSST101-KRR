# CSST101 Webpage

Google Classroom-inspired responsive course webpage for:
CSST101 – Advanced Representation and Reasoning
AI + R Programming + Data Science + Case Studies

## Files
- index.html — complete standalone webpage (HTML/CSS/JavaScript)

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Go to Settings → Pages.
4. Choose the main branch and root folder.
5. Save, then open the generated GitHub Pages URL.

The webpage content is based on the supplied CSST101 syllabus for AY 2025–2026.
