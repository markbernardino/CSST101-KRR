📘 Course Overview

Outcomes-based learning program

This course introduces advanced knowledge representation and reasoning techniques in artificial intelligence, including non-monotonic reasoning, argumentation, reasoning about action and change, temporal and spatial reasoning, rule-based expert systems, semantic networks, model-based and case-based reasoning, and planning.

Data Analytics and Data Science are integrated for evidence-based knowledge construction, exploratory data analysis, data visualization, feature representation, similarity analysis, and evaluation of intelligent systems. Modern AI approaches include Generative AI, Large Language Models (LLMs), Knowledge Graphs, Retrieval-Augmented Generation (RAG), AI-assisted reasoning, and explainable AI.

Core workflow: Data → Analysis → Knowledge Representation → Reasoning → AI Assistance → Verification → Decision

🎯 Course Intended Learning Outcomes

CILOIntended Learning Outcome
CILO1Identify and explain ethical issues in AI, data management, Generative AI, and knowledge-based systems.

CILO7Evaluate AI-generated outputs using logical verification, evidence, and reproducible computational methods.
CILO8Develop an AI-assisted Knowledge Representation and Reasoning application using R, with appropriate documentation, testing, and presentation.

💻 R Programming Laboratory

Laboratory Scope

  • R Fundamentals: variables, vectors, matrices, lists, data frames, functions, control structures, packages, scripts and projects.
  • Logic Programming: Boolean expressions, truth tables, rule evaluation and satisfiability checking.
  • Knowledge Bases: facts, predicates, rules, structured lists/data frames and query functions.
  • Inference: forward/backward chaining, unification concepts and resolution simulation.
  • Graph Reasoning: argument graphs, semantic networks, path reasoning and network visualization.
  • Temporal/Spatial Reasoning: date/time objects, intervals, constraints, coordinates, adjacency and path finding.
  • Expert Systems: rule engines, explanation traces, test cases and optional Shiny interfaces.
  • Case-Based Reasoning: feature representation, similarity, retrieval and adaptation.

Standard Laboratory Output

  • Problem statement and real-world context
  • Dataset description and data dictionary
  • R cleaning and exploratory analysis script
  • At least two meaningful visualizations where applicable
  • Knowledge representation
  • Reasoning algorithm and R implementation
  • AI prompt/output evidence when AI is used
  • Verification/comparison of AI and R/KRR results
  • Interpretation and recommendation
  • Limitations, ethics and reflection

🤖 AI Integration & Academic Integrity

Approved Uses

  • Brainstorming and explanation
  • Code assistance and debugging
  • Comparison activities
  • Natural-language interaction
  • Candidate entity/relation extraction
  • RAG or AI-assisted components when approved

Student Responsibilities

  • Test, understand and document AI-generated code and explanations.
  • Verify AI-generated logical conclusions using R, formal reasoning, test cases or authoritative evidence.
  • Disclose substantial AI assistance, including tool and purpose.
  • Do not submit fabricated citations, invented results or unverified AI claims.
  • Do not enter sensitive, confidential, personal or protected information into public AI systems.
  • Be prepared for oral defense, live coding or reproducibility checks.

🚀 Recommended Capstone Project

AI-Powered Knowledge Representation and Reasoning System Using R

Students design and implement a real-world intelligent system that explicitly represents knowledge and performs reasoning. R is the primary laboratory language; an approved LLM or local model may be incorporated as an AI-assisted component.

Minimum Requirements

  • Knowledge representation: facts, rules, predicates, semantic network, ontology or knowledge graph
  • At least one explicit reasoning mechanism
  • Working R code, functions, data structures, tests and reproducible execution
  • Approved AI component such as LLM, RAG or AI-assisted extraction

Evaluation & Documentation

  • Test cases comparing AI output with symbolic/rule-based reasoning
  • Explainability through facts/rules/evidence
  • Technical report, diagrams, limitations, ethics and AI-use disclosure
  • Working demonstration and oral defense
